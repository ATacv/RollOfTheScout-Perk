# RollOfTheScout 改造总结 · 文档索引

本文汇总这次对 [RollOfTheScout](https://github.com/Rhys-214/RollOfTheScout) 的全部改造、当前状态、配置口径与遗留工作。
仓库原件是「31 个职业随机分配」的 PEAK 模组，本次改造把它变成了**词条（perk）驱动**的玩法。

---

## 一、核心玩法变化

| 项 | 改造前 | 现在 |
|---|---|---|
| 职业 | 每局随机分配 1 个职业 | **默认不再分配职业**（`词条-模式 = 替换`），可切回「叠加」 |
| 效果来源 | 职业自带的 4~6 条效果 | **每关抽词条**：正面 2~3 + 负面 2~3 + 怪谈 1 |
| 词条总数 | — | **81 条**（目录内，含 6 条参数化模板实例） |
| 面板（按住 Tab） | 每人一行「昵称：职业」 | 每人一行昵称 + 每条词条一行的列表 |
| 换词条 | 吃诡异菇转职 | 做「不行不行」表情 → **重抽词条**（并清空体力条 + 清空全部负面状态） |
| 怪谈词条 | 无 | 独立池，18 条惩罚型词条，面板不显示 |

## 二、已实现的系统

### 1. 词条系统（`Mod/RollOfTheScout/Perks.cs`）
- `Perk` 基类：`Id / NameZh / DescZh / DescEn / Category / Weight / ExcludeGroup`，钩子 `OnDraw / Tick / OnRemove / OnPlayerDeath`
- 每玩家独立计时器（`Due / State / SetState`），一个词条类可服务所有玩家
- 三条抽签线：正面 / 负面 / 怪谈，跨池按 Id 去重、按互斥组互斥
- 代际 hook：`OnPlayerDeath`（死亡事件）+ `TryPerkEmoteEffects`（表情事件）+ `TryPerkPickup`（拾取事件）
- 参数化模板 `PerkDrain`：一句 `new PerkDrain(...)` 即一条「周期增减某项状态」的词条

### 2. 怪谈词条（18 条）
深度冻伤 / 外皮烧伤 / 肉体穿刺 / 肢体僵硬 / 真假死 / 猜忌 / 过度依赖 / 过量饮食 / 力竭 / 眼球脆弱 / 夜盲症 / 眩光症 / 多动症 / 白化病 / 筋骨劳损 / 待皓的祝福 / 翻跟头的人 / 别做表情。
- **秒杀类递进惩罚**：第 1 次 +10 损伤，第 2 次 +20 损伤，第 3 次起秒杀
- **强制表情不算触犯**，**后空翻本身也不算**
- 三条「坏蘑菇」词条（过量饮食 / 力竭 / 过度依赖）走原版 `Action_RandomMushroomEffect`，可用 `useDebugEffect + debugEffect` **固定效果索引**（配置项 `坏蘑菇-xxx效果索引`）

### 3. ATacv 职业（第 31 个职业）
自带绳索 / 心痛（真丢弃才扣损伤，带使用事件屏蔽）/ 收编后宫 / 沉默者 / 自挂东南枝 / 本地换装。

### 4. 本地换装（`啥子装出行`）
用原版（private static）`CharacterCustomization.GetCustomizationData / SetCustomizationData` 改外观数据，再让本机该角色重新套一遍。
**只在装了本模组的客户端可见**，未装模组玩家仍是原样。每 5 秒巡检防覆盖。

### 5. 拾取层（骨架已就绪）
新增 `PerkPickupPatch`（挂 `Player.AddItem`），通过 `ref ushort itemID` **就地改写**拾取物，不改动原有 8 个职业补丁。
第一条实现：刺客【刺杀】10% 变仪式匕首。

## 三、配置口径（`BepInEx/config/com.peakmodding.RollOfTheScout.cfg`）

| 板块 | 关键项 |
|---|---|
| `词条` | `启用` / `模式`（替换·叠加）/ `正面-最少·最多` / `负面-最少·最多` / `怪谈-数量` / `怪谈-启用` / `怪谈-权重` / `坏蘑菇-*-效果索引` / 每条词条一个 `xxx-启用` |
| `通用` | `转职-表情`（默认「不行不行」）/ `转职-表情启用`（默认开）/ `转职-次数`（默认 1000） |
| `ATacv` | 绳索数量/物品、心痛、收编后宫、沉默者、自挂东南枝、外观-* |

## 五、已知限制

| 限制 | 原因 |
|---|---|
| 换装只在装模组端可见 | 原版无任何外观同步 RPC / 字段 |
| 眩光症 / 白化病的「阴影」未区分 | 原版没有可读的「处于阴影」状态 |
| 【无痛症】未实现 | 隐藏状态栏属 UI 层，需 hook 状态栏组件 |
| 拾取类只有 1 条 | 其余 9 条需逐条接 `TryPerkPickup`（「消失」类要走取消拾取通道，不能靠 ref itemID） |

## 七、构建与安装

```bash
# 构建（本机已配好 Config.Build.user.props 指向 E 盘 PEAK）
dotnet build Mod/RollOfTheScout/RollOfTheScout.csproj -c Release
# 产物
#   Mod/RollOfTheScout/bin/Release/com.peakmodding.RollOfTheScout.dll
# 安装（必须先关游戏，否则 dll 被占用）
#   复制到 E:\SteamLibrary\steamapps\common\PEAK\BepInEx\plugins\
```
